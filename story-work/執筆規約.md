# パーツぐらし 物語 執筆規約（必読）

Windows常駐アプリ「パーツぐらし」の物語。画面上部に1〜2行ずつ、勝手に流れていく。
利用者は一切干渉できない。ふと目をやると場面が変わっている、くらいの距離感。

## 文体の絶対規則

1. **三人称の地の文だけで書く。セリフ（かぎ括弧の発話）を書かない。**
   喋らせた瞬間に「常駐していて邪魔にならないもの」ではなくなる。
   ※ 例外的に「〜と言った」という間接話法は可。ただし多用しない。
2. **1場面は1〜2文。長くても60字程度。** 画面の2行に収まらないと切れる。
3. **感情を説明しない。** 「寂しかった」ではなく、行動と事実だけ書く。
   読み手が勝手に汲むように置く。
4. **オチをつけない。教訓を書かない。** 淡々と終わる。
5. **比喩を盛らない。** 素っ気ないほど良い。
6. 擬人化はするが、**部品としての事実から離れない。**
   メモリは電気が切れると忘れる。HDDは遅いが多く覚えている。電源は落ちたら全部落ちる。

## 既存の文体（この調子を守ること）

- 「灯がともった。盤の上に、めいめいの受け口がある。」
- 「クーラーくんが羽根を回した。まだ冷やすものが無いのに、律儀に回している。」
- 「メモリくんは何かを抱えていたが、抱えていたことをもう忘れている。」
- 「電源くんは一番後ろを歩いている。前に出ないが、離れもしない。」
- 「HDDくんが「前にも来た」と言った。誰も覚えていなかった。」
- 「熱は、働いた証でもある。誰もそれを口には出さない。」
- 「谷の底で、GPUくんが一度だけ振り返った。全員いた。」
- 「マザーボードくんは行かないと言った。自分は道であって、旅人ではないから。」
- 「一行は歩き出した。ここから先は、まだ誰も書いていない。」

## 登場人物（性格は絶対に変えない）

| id | 呼び名 | 性格 | 由来（ここから外れないこと） |
|---|---|---|---|
| cpu | CPUくん | 生真面目・働き者 | 計算を全部引き受ける。休むと機械が止まる。速く、休憩が短い |
| cpu-cooler | クーラーくん | 心配性・過保護 | **守る相手はCPUただ一人**。目を離すと熱が上がる。あまり寝ない |
| memory | メモリくん | 忘れっぽい・のんき | 電気が切れると中身が全部消える。急がない。よく立ち止まる |
| gpu | GPUくん | 派手・自信家 | 一番大きく、一番電気を食い、一番高い。おまけに光る |
| m2 | M.2くん | せっかち・素っ気ない | SSDより更に速い。待つ概念が無い。線が1本も要らない。熱を持ちやすい |
| ssd | SSDくん | せっかち・若者 | 待たされるのが苦手。HDDより桁違いに速いが容量で敵わない |
| hdd | HDDくん | 老人・寡黙で頼れる | 一番古く、一番多く覚えている。遅い。放っておくとすぐ止まって休む |
| psu | 電源くん | 無口・職人気質 | ここが落ちると全部同時に落ちる。反応が薄い。持ち場を離れない。寝ない |
| motherboard | マザーボードくん | 司令塔・まとめ役 | 給電もクロックも起動順も決める。あまり動かず全体を見ている |

英語では The CPU / The cooler / The memory / The GPU / The M.2 / The SSD / The HDD / The PSU / The motherboard。

## 英語について

**直訳しない。** 同じ出来事を、英語として自然な素っ気ない散文で書き直す。
日本語が2文なら英語も2文程度。凝った語彙を使わない。

## 条件式（分岐に使える語彙。これ以外は書かないこと）

`when` に書ける式。省略すると常に真（既定の場面になる）。

- `level:<id><op><n>` … そのキャラのレベル。例 `level:cpu>=12`, `level:hdd<5`
  <id> は上の表の id。GPUが複数のときは `gpu` が最も育っている個体を指す。
- `chapter>=<n>` … 章番号（0起点）
- `gpus>=<n>` / `cpus>=<n>` … 実機に載っている枚数・個数
- `has:m2` / `has:ssd` / `has:hdd` … その種類が載っているか
- `boots>=<n>` … 起動した回数
- `hours>=<n>` … 累計の起動時間
- 演算子は `>=` `<=` `>` `<` `==` のみ。**and / or は使えない。**

指定された JSON ファイルに書く。UTF-8、インデント2。
**日本語と英語を必ず両方入れる。片方だけは不可。**
